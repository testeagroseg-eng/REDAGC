# Agroseg Connect — página de retorno pós-checkout

Página estática e responsiva para receber o comprador depois do checkout Mercado Pago.

Este repositório é separado da landing page comercial. **Um redirecionamento ou parâmetros de URL não provam que um pagamento foi aprovado**. A liberação de acesso exige confirmação segura do pagamento no backend (API / notificações Mercado Pago) e provisão da conta no Agroseg Connect.
